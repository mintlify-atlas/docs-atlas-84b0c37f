Carbonkrishi is a climate-smart, AI-powered Life Cycle Assessment (LCA) platform built specifically for rice agriculture. It exposes a suite of REST API endpoints that let rice farmers, agronomists, sustainability researchers, and developers building agri-tech tools quantify the environmental footprint of fertiliser inputs, estimate field-level greenhouse gas emissions, optimise nutrient blends, and calculate soil-organic-carbon credit potential — all from a single, open API.

## Fertiliser Regimes

Carbonkrishi models two distinct fertiliser management strategies common across South and South-East Asian rice systems:

| Regime | Inputs | Description |
|---|---|---|
| **Conventional** | N, P, K, Zn | Synthetic NPK fertiliser plus zinc micronutrient (kg ha⁻¹) |
| **Organic** | FYM, Compost | Farm Yard Manure and compost amendments (kg ha⁻¹) |

Both regimes are modelled through independent Ridge regression models trained on OpenLCA-derived impact data. The blend endpoint accepts inputs from both regimes simultaneously and returns a weighted composite using a user-defined `alpha` parameter.

## LCA Impact Categories

Every prediction response returns four environmental impact indicators drawn from the ReCiPe 2016 midpoint methodology:

| Impact Category | Field Name | Unit |
|---|---|---|
| **Global Warming Potential** | `global_warming` | kg CO₂-eq |
| **Freshwater Eutrophication** | `freshwater_eutrophication` | kg P-eq |
| **Terrestrial Acidification** | `terrestrial_acidification` | kg SO₂-eq |
| **Terrestrial Ecotoxicity** | `terrestrial_ecotoxicity` | CTUe |

Per-kg environmental footprints (computed in OpenLCA) are embedded as constants and used by the inference engine to contextualise results for farmers in their local language.

## Technology Stack

Carbonkrishi is built on a modern, lightweight Python stack designed for fast inference and easy deployment:

| Layer | Technology |
|---|---|
| **Web framework** | FastAPI ≥ 0.110 |
| **ML inference** | scikit-learn Ridge regression, joblib, numpy, pandas |
| **Data validation** | Pydantic v2 |
| **Server** | Uvicorn (ASGI) |
| **Containerisation** | Docker (python:3.11-slim) |

ML models are serialised as `.pkl` files and loaded once at application startup via a `lifespan` context manager, keeping per-request inference overhead minimal.

<Note>
  **No authentication required.** All Carbonkrishi API endpoints are fully open. There are no API keys, tokens, or rate limits to configure before making your first request.
</Note>
