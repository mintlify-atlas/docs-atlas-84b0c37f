title: "POST /api/inference/card — Multilingual Agronomic Inference Cards"
sidebarTitle: "Inference"
description: "POST /api/inference/card — generate a farmer-facing explanation card for an LCA or emission metric in English, Hindi, Telugu, or Marathi with color-coded severity and cited sources."
---

The inference card endpoint converts a numeric domain value into a plain-language explanation card with actionable agronomic recommendations, a severity colour, and a list of cited references. Cards are available in four languages — English, Hindi, Telugu, and Marathi — and adapt their message based on threshold comparisons against domain-specific reference values. The optional `ctx` object unlocks richer, context-aware guidance (e.g. irrigation mode for CH₄, zinc level for ecotoxicity).

## POST /api/inference/card

### Request Body

<ParamField body="domain" type="string" required>
  The metric domain to interpret. Must be exactly one of:

  | Value | Description |
  |-------|-------------|
  | `gwp_total` | Total global warming potential (kg CO₂-eq/ha) |
  | `ch4` | Methane emissions (kg CH₄/ha/season) |
  | `n2o` | Nitrous oxide emissions (kg N₂O/ha/season) |
  | `no3` | Nitrate leaching potential (kg NO₃/ha/season) |
  | `nh3` | Ammonia volatilisation (kg NH₃/ha/season) |
  | `po4` | Phosphate runoff potential (kg PO₄/ha/season) |
  | `ecotox` | Terrestrial ecotoxicity (CTUe/ha) |
  | `credits` | Net SOC carbon credits (t CO₂-eq/ha) |
  | `blend_savings` | GWP saving from a fertiliser blend scenario (kg CO₂-eq/ha) |
</ParamField>

<ParamField body="value" type="float" required>
  The numeric metric value to interpret. Must match the natural units of the chosen domain (see the domain table above). The engine compares this value against curated reference thresholds to determine a severity band (low / mid / high) and select the appropriate message.
</ParamField>

<ParamField body="ctx" type="object">
  Optional context dictionary that enables domain-specific adaptive messaging. The accepted keys vary by domain — see the table below. Keys not recognised by the domain handler are silently ignored.

  | Domain | Supported `ctx` keys | Type | Effect |
  |--------|----------------------|------|--------|
  | `gwp_total` | `irrigation` | string | Tailors AWD advice if already practising AWD |
  | `gwp_total` | `amendments_used` | boolean | Adds FYM recommendation if no amendments are in use |
  | `ch4` | `irrigation` | string | Selects AWD-specific or rainfed-specific messaging |
  | `n2o` | `synthetic_n` | float | Triggers high-N dose-reduction advice if > 145 kg/ha |
  | `ecotox` | `zinc` | float | Flags zinc over-application if > 20 kg/ha |
  | `blend_savings` | `gwp_saved` | float | GWP reduction in kg CO₂-eq/ha relative to conventional |
  | `blend_savings` | `cost_delta` | float | Cost difference in INR/ha (positive = extra cost, negative = saving) |
  | `blend_savings` | `alpha` | float | Blend fraction 0.0–1.0 used for the scenario |
  | All others | — | — | No ctx needed; `ctx` is ignored if supplied |
</ParamField>

<ParamField body="lang" type="string" default="en">
  Response language. One of `"en"` (English), `"hi"` (Hindi), `"te"` (Telugu), `"mr"` (Marathi). Marathi falls back to Hindi for any text string where an explicit Marathi translation has not been provided.
</ParamField>

### Response Body

<ResponseField name="title" type="string">
  Localised card title including an emoji severity indicator. Examples: `"🌍 Global Warming"`, `"🔥 मीथेन (CH₄)"`, `"💎 కార్బన్ క్రెడిట్ సామర్థ్యం"`.
</ResponseField>

<ResponseField name="body_html" type="string">
  HTML body string containing the explanation and recommendations. Only `<b>` and `<i>` inline tags are used — these come from hand-written templates with no user input, so direct `innerHTML` rendering on the client is safe. Numeric values are embedded with locale-appropriate formatting (commas, decimal places).
</ResponseField>

<ResponseField name="color" type="string">
  Hex colour code reflecting the severity band:

  | Color | Hex | Meaning |
  |-------|-----|---------|
  | Green | `#16a34a` | Below the lower threshold — low risk or good performance |
  | Amber | `#f59e0b` | Within the expected range — moderate risk |
  | Red | `#ef4444` | Above the upper threshold — high risk, action recommended |
</ResponseField>

<ResponseField name="refs" type="object[]">
  Array of citation objects drawn from the central source registry. Use these to populate a "References" section on the card.

  <Expandable title="ref object fields">
    <ResponseField name="key" type="string">
      Short citation key, e.g. `"ipcc_ar6"`, `"gold_awm"`, `"moefcc_ccts"`.
    </ResponseField>
    <ResponseField name="name" type="string">
      Full display name of the source, e.g. `"IPCC AR6 Working Group I (2021)"`.
    </ResponseField>
    <ResponseField name="url" type="string">
      Canonical URL for the cited document or dataset.
    </ResponseField>
  </Expandable>
</ResponseField>

### Example Requests

**Global warming impact — English:**

```bash
curl -X POST https://carbonkrishi.onrender.com/api/inference/card \
  -H "Content-Type: application/json" \
  -d '{
    "domain": "gwp_total",
    "value": 5200,
    "ctx": {
      "irrigation": "Fully Flooded",
      "amendments_used": false
    },
    "lang": "en"
  }'
```

### Error Responses

| Status | Detail |
|--------|--------|
| `400 Bad Request` | `domain` value is not one of the nine recognised strings. Response body: `{"detail": "Unknown domain: <value>"}` |
